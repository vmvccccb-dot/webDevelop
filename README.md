# Valle Alegre — Landing demo

Landing estática en Next.js, preparada para Vercel. No incluye backend: el formulario muestra una confirmación local y no envía datos.

## Ejecutar en local

1. Instala Node.js 18.17 o superior.
2. En esta carpeta ejecuta `npm install`.
3. Ejecuta `npm run dev` y abre la dirección indicada por Next.js.

## Desplegar en Vercel

Importa este repositorio/carpeta desde Vercel. La plataforma detectará Next.js y usará automáticamente `npm run build`.

Los medios se encuentran en `public/media/`; la portada reproduce `valle-alegre.mp4` de forma automática, sin sonido y en bucle.
